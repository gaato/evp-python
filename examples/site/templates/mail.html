pyevp mock email provider

This mock email provider plays the issuer in the pyevp demo. Anyone can sign in as {{ email }} and let the browser request a token for that address.

Signing in sets a signed session cookie so this provider can remember your choice when the browser asks for accounts or a token. It also tells the browser that you are logged in, so the browser can offer this account to the demo.

{{ email }} is not a mailbox. A token for it proves nothing: it only means someone pressed the sign-in button. Use it solely to try the demo.
