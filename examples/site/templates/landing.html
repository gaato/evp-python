pyevp

Verify email addresses in Python with a token from the user's email provider.

Try the demo

How it works

  1. The browser asks the user's email provider for a token.
  2. The provider vouches for the email address by signing the token.
  3. Your server verifies the token with pyevp.

See the compatibility guide for browser support and deployment requirements.

Getting started

pip install "pyevp[all]"
